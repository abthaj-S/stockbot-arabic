# StockBot Arabic 🤖

An Arabic-language inventory management bot for small businesses, built with Python and Telegram.

## Problem
Small businesses in Saudi Arabia manage their inventory manually using paper or WhatsApp messages — leading to stock shortages, human errors, and wasted time.

## Solution
A Telegram bot that understands Arabic commands, tracks inventory in real time, and alerts the owner when stock is running low.

## Features
- Add stock: `اضف 10 أرز`
- Check quantity: `كم باقي من أرز`
- Full inventory report: `تقرير`
- Auto-alert when stock reaches 5 units or below ⚠️

## Tech Stack
- Python 3
- python-telegram-bot
- Flask
- JSON (local storage)

## How to Run
1. Clone the repository
2. Install dependencies: `pip install python-telegram-bot flask`
3. Add your Telegram bot token in `bot.py`
4. Run: `python bot.py`
