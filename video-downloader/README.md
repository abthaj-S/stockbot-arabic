# تحميلي 🎀

تطبيق ويب بواجهة عربية لطيفة وعصرية لتحميل مقاطع الفيديو من الروابط بجودة عالية.

## المميزات
- 🎬 **فيديو كامل بالصوت** بصيغة MP4، بأعلى جودة متاحة (حتى 4K) أو بالجودة التي تختارها
- 🔇 **فيديو بدون صوت**: يحذف الصوت بدون إعادة ترميز، فالجودة تبقى كما هي تماماً
- 🎵 **صوت فقط**: بصيغة MP3 أو M4A أو WAV، مع اختيار معدل البت (128 إلى 320 kbps)
- 🌐 يدعم يوتيوب، تيك توك، إنستغرام، X، فيسبوك، ساوند كلاود، وأكثر من 1000 موقع (عبر [yt-dlp](https://github.com/yt-dlp/yt-dlp))
- 📊 شريط تقدم حي يعرض السرعة والوقت المتبقي
- 🌙 وضع ليلي، ويعمل على الجوال
- 🧹 تُحذف الملفات من الخادم تلقائياً بعد ساعة

## التشغيل
```bash
cd video-downloader
pip install -r requirements.txt
python app.py
```
بعدها افتح المتصفح على: http://127.0.0.1:5000

> التطبيق يستخدم `ffmpeg` المثبّت على جهازك إن وُجد، وإلا يستخدم النسخة المرفقة مع حزمة `imageio-ffmpeg` تلقائياً، فلا تحتاج لتثبيت أي شيء إضافي.

لتشغيله على الشبكة المحلية (مثلاً لفتحه من الجوال) **لازم** تحط كلمة مرور، وإلا يرفض التطبيق التشغيل:
```bash
HOST=0.0.0.0 PORT=8000 APP_PASSWORD='كلمة-مرور-قوية' python app.py
```

## 🔒 الأمان
| الحماية | وش تسوي |
|---|---|
| منع SSRF | يرفض أي رابط يشير لعناوين داخلية (الراوتر، localhost، `169.254.169.254`…) |
| المواقع المعروفة فقط | الروابط المباشرة للملفات مقفلة افتراضياً، فالتطبيق يتصل فقط بالمواقع المدعومة |
| كلمة مرور | `APP_PASSWORD` تحمي التطبيق، وإلزامية إذا فتحته على الشبكة |
| حد الطلبات | 20 طلب معلومات بالدقيقة و10 تحميلات كل 10 دقائق لكل IP، و3 تحميلات متزامنة كحد أقصى |
| حد الحجم والمدة | 2GB و3 ساعات كحد أقصى، ويرفض التحميل إذا بقي أقل من 1GB على القرص |
| ملكية الملفات | كل ملف مربوط بكوكي سري، فما أحد غيرك يقدر ينزّله حتى لو عرف الرابط |
| حماية المتصفح | CSP ومنع التضمين (Clickjacking) وحماية CSRF وحماية DNS rebinding |
| خادم إنتاج | يشتغل على `waitress` بدل خادم التطوير |
| الخصوصية | الملفات تنحذف بعد ساعة، ورسائل الخطأ ما تكشف تفاصيل الخادم |

إعدادات اختيارية:
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `APP_PASSWORD` | — | كلمة مرور الدخول |
| `ALLOWED_HOSTS` | localhost | أسماء النطاق المسموحة (مثل `mysite.com`) |
| `ALLOW_DIRECT_LINKS` | `0` | `1` للسماح بروابط الملفات المباشرة (`.mp4`…) |
| `MAX_FILESIZE_MB` | `2048` | الحد الأقصى لحجم الملف |
| `MAX_DURATION_MIN` | `180` | الحد الأقصى لمدة المقطع |
| `MAX_ACTIVE_JOBS` | `3` | عدد التحميلات المتزامنة |

> 💡 إذا بتنشره على الإنترنت، حطه خلف HTTPS (مثل Caddy أو Nginx) عشان كلمة المرور ما تنرسل بدون تشفير، وحدّث المكتبات بانتظام: `pip install -U -r requirements.txt`

## نصائح
- إذا توقّف التحميل من موقع معيّن، حدّث yt-dlp لأن المواقع تتغير باستمرار:
  `pip install -U yt-dlp`
- استخدم التطبيق فقط للمحتوى الذي تملك حق تحميله.

## واجهة البرمجة (API)
| المسار | الوصف |
|---|---|
| `POST /api/info` `{url}` | معلومات المقطع: العنوان، الصورة المصغّرة، المدة، والجودات المتاحة |
| `POST /api/download` `{url, mode, quality, audio_format, bitrate}` | يبدأ التحميل ويرجع `job_id`. قيم `mode`: `video`، `mute`، `audio` |
| `GET /api/progress/<job_id>` | حالة التحميل ونسبة التقدم |
| `GET /api/file/<job_id>` | تنزيل الملف الجاهز |
