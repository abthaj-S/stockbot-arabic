# تحميلي 🎀

تطبيق ويب بواجهة عربية لطيفة وعصرية لتحميل مقاطع الفيديو من الروابط بجودة عالية.

## المميزات
- 🎬 **فيديو كامل بالصوت** بصيغة MP4، بأعلى جودة متاحة (حتى 4K) أو بالجودة التي تختارها
- 🔇 **فيديو بدون صوت**: يحذف الصوت بدون إعادة ترميز، فالجودة تبقى كما هي تماماً
- 🎵 **صوت فقط**: بصيغة MP3 أو M4A أو WAV، مع اختيار معدل البت (128 إلى 320 kbps)
- 🌐 يدعم يوتيوب، تيك توك، إنستغرام، X، فيسبوك، ساوند كلاود، وأكثر من 1000 موقع (عبر [yt-dlp](https://github.com/yt-dlp/yt-dlp))
- 📊 شريط تقدم حي يعرض السرعة والوقت المتبقي
- 🌙 وضع ليلي، ويعمل على الجوال
- 🧹 تُحذف الملفات من الخادم تلقائياً بعد ساعة

## التشغيل
```bash
cd video-downloader
pip install -r requirements.txt
python app.py
```
بعدها افتح المتصفح على: http://127.0.0.1:5000

> التطبيق يستخدم `ffmpeg` المثبّت على جهازك إن وُجد، وإلا يستخدم النسخة المرفقة مع حزمة `imageio-ffmpeg` تلقائياً، فلا تحتاج لتثبيت أي شيء إضافي.

لتشغيله على الشبكة المحلية (مثلاً لفتحه من الجوال):
```bash
HOST=0.0.0.0 PORT=8000 python app.py
```

## نصائح
- إذا توقّف التحميل من موقع معيّن، حدّث yt-dlp لأن المواقع تتغير باستمرار:
  `pip install -U yt-dlp`
- استخدم التطبيق فقط للمحتوى الذي تملك حق تحميله.

## واجهة البرمجة (API)
| المسار | الوصف |
|---|---|
| `POST /api/info` `{url}` | معلومات المقطع: العنوان، الصورة المصغّرة، المدة، والجودات المتاحة |
| `POST /api/download` `{url, mode, quality, audio_format, bitrate}` | يبدأ التحميل ويرجع `job_id`. قيم `mode`: `video`، `mute`، `audio` |
| `GET /api/progress/<job_id>` | حالة التحميل ونسبة التقدم |
| `GET /api/file/<job_id>` | تنزيل الملف الجاهز |
